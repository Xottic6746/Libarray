# Libarray

A polished React movie catalog for public, open-access film listings.

## Run locally

1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Open the local URL shown in the terminal.

## Build

npm run build

## Notes

- Add your own valid public streaming URLs to `src/data/movies.js`.
- For legal compliance, only include films you have verified are allowed to be streamed publicly.
